# AppUsuarios — User Management App

An Angular application for managing users with full CRUD operations, profile views, and role assignment.

## Tech Stack

| Layer | Technologies |
|-------|-------------|
| Frontend | Angular, TypeScript |
| UI | Angular Material / Bootstrap |
| Backend | REST API |

## Features

- User listing with search and filters
- Create, edit, and delete users
- Role and permission assignment
- User profile detail view
- Form validation
